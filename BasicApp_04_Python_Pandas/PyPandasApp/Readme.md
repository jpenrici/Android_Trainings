# PyPandasApp

A modern Android application built with **Jetpack Compose** that leverages **Chaquopy** to bring Python's 
data science ecosystem specifically the **Pandas** library directly into the native Android environment.

---

## Tech Stack

* **[Android Jetpack Compose](https://developer.android.com/jetpack/compose):** Modern, declarative toolkit for building native Android UIs.
* **[Chaquopy](https://chaquopy.com/):** Gradle plugin that allows you to run Python code directly inside Android apps, bridging Kotlin/Java and Python libraries.
* **[Pandas](https://pandas.pydata.org/):** Powerful Python library for data manipulation, cleaning, and tabular analysis.
* **[Kotlin](https://kotlinlang.org/):** Primary programming language for the project.
